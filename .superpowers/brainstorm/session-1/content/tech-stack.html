Texnologik Stek va Android Ishlash Formati

5-Tab Executive OS ilovasini ishlab chiqish va telefonda ishga tushirish uchun qaysi texnologik yondashuvni tanlaymiz?

A

React Native + Expo (Native Android APK)

Haqiqiy Android ilova (.apk/.aab). Telefonda to'liq mahalliy ishlaydi:

  • Native timer, tebranish (haptic feedback) va "Do It Now!" fon xabarnomalari.
  • Tizimli DND (Do Not Disturb) rejimini yoqish imkoniyati.
  • Google Play'ga yoki to'g'ridan-to'g'ri telefonga o'rnatish.
B

Vite + React Mobile PWA (Installable Android Web App)

Darhol ishga tushadigan, telefonga ilova sifatida o'rnatiladigan eng tezkor va chiroyli variant:

  • [DESIGN.md] ichidagi barcha Auros CSS tokenlari, animatsiyalar va bioluminessent gradientlar 100% cheklovlarsiz ishlaydi.
  • Brauzerda ham, Android ekranida ham alohida ilova sifatida ochiladi (Offline rejimida ham ishlaydi).
  • Hech qanday og'ir Android SDK/Gradle o'rnatishni talab qilmaydi.
C

Capacitor / Hybrid (Web UI + Native Android Wrapper)

Ikkala dunyoning eng yaxshi tomonlari:

  • Auros dizayni to'liq zamonaviy Web texnologiyalarida quriladi.
  • Capacitor orqali to'g'ridan-to'g'ri Android Studio loyihasiga o'ralib, APK qilib chiqariladi.
